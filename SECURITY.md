# Reporting a vulnerability

Please use [private vulnerability reporting](https://github.com/dylan-murray/agent-desk/security/advisories/new)
to report ways another website, another session, or an agent can reach terminals it should not,
exposed tokens, or other security issues. Do not include exploit details or secrets in public
issues or pull requests.

Include the affected commit, your OS and browser, reproduction steps, and expected versus
observed behavior.

The project is pre-release. Security fixes target the latest main branch until versioned
releases establish a support policy. See [Who can reach a session](docs/guide.md#who-can-reach-a-session)
for the access model and its known limits.
